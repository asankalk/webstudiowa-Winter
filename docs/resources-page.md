# Resources hub

- **Template:** `page-resources.php`
- **URL:** `/resources/`

The hub includes resource categories, 12 static suggested article cards, a plugins CTA, and a contact CTA. The article cards are planned/static only; they deliberately do not link to pages that do not exist yet.

Suggested article topics cover WordPress security and access, maintenance, image accessibility and SEO, and social-feed API workflows. A future step can add real blog posts or a dedicated resource custom post type.

## WordPress admin setup

Create and publish a page named **Resources** with slug `resources`. WordPress automatically applies `page-resources.php`.
