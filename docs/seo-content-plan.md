# Web Studio WA SEO content plan

This plan is based on site structure and service intent, not Search Console, analytics or ranking data. Validate priorities with live tools before expanding production content.

## Priority topics and supporting pages

| Topic cluster | Initial content | Primary supporting page |
| --- | --- | --- |
| WordPress access and website care | The six access, role, 404 and security guides now in Resources | `/plugins/admin-watch/`, `/website-maintenance/` |
| Image SEO and accessibility | The three alt-text and image-preparation guides | `/web-design/`, `/website-maintenance/` |
| Social media feeds | The three Instagram, Facebook, OAuth and Meta-review guides | `/plugins/socialfeed/`, `/plugins/` |
| Website redesign planning | Plan a redesign without losing useful content | `/website-redesign/` |
| Hosting support | Choosing practical business website hosting support | `/web-hosting/` |

## Recommended publishing order

1. Confirm all 12 Resources URLs resolve, are linked from `/resources/`, and are indexable.
2. Publish or refine the access and maintenance cluster first, with links to Admin Watch and maintenance support.
3. Refine the image SEO/accessibility cluster, linking to web design and maintenance where relevant.
4. Refine the social-feed cluster only as SocialFeed capabilities and Meta permissions are confirmed.
5. Add a redesign-planning guide and a hosting-support guide after the existing clusters are established.

## Service-page and case-study improvements

Keep service pages commercial and concise. Add approved evidence over time: a clear client problem, the agreed scope, the pages or improvements delivered, and any factual outcome the client permits Web Studio WA to state. Do not invent results, reviews or rankings.

## Internal linking pattern

Each guide should link to one relevant product or service, one natural related guide and a support/contact option. Service and plugin pages should link to only the guides that genuinely help a visitor decide what to do next. Use descriptive anchors rather than repeating target keywords.

## 30-day plan

1. Save permalinks and inspect the homepage, services, Plugins, Resources and new guides in Search Console.
2. Submit the XML sitemap and resolve indexing or canonical issues shown by live reports.
3. Verify each guide has its intended internal links and one clear conversion path.
4. Add approved screenshots to Admin Watch and SocialFeed when available.
5. Review Google Business Profile details, real photos and relevant destination links.

## 90-day plan

1. Review Search Console query and page trends monthly after meaningful data has accumulated.
2. Publish the redesign-planning and hosting-support guides if they match verified customer questions.
3. Add one or two consented case studies using the format above.
4. Improve pages based on verified crawl, query and conversion signals rather than assumptions.
